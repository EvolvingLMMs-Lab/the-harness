The prompts say in one place what counts as tried, and everything else follows it: a thing is built for the hardest form of what it has to meet, it is tried in the least case that shows whether it does what it is for, and when it does it is done. The core prompt no longer asks for the hardest form to be tried first or for more trials the more a failure would cost; the instruction of a practice run no longer asks for everything to work more than once (only where the outcome depends on chance) and says that a node of the tree of reflexes is tried as the tree's page says. That page says to set every node that was laid out, each with its one trial, before coming back to any of them.

提示词只在一处说明怎样算试过，其余各处都跟它一致：一样东西照它要应对的最难情况来做，用能看出它是否达到目的的最小情况来试，达到了就算完成。主提示词不再要求先试最难的情况，也不再要求失败代价越高试得越多；练习说明不再要求每样东西都做成不止一次（只有结果靠运气的才多做），并说明反射树的节点按树自己那一页的办法来试。那一页要求把铺开的每个节点都设上、各带一次试验，然后才回头修。
