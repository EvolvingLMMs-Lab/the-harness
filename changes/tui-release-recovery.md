The terminal chat keeps background startup and shell results with their original conversation, reconnects after losing its host, and manages packages through the running host. Program details retain complete output, long paragraphs and drafts wrap correctly, and large details reuse their rendering until content or width changes; host reads remain responsive and can be dismissed while waiting. Explicit command-line model choices remain selected when changing reasoning effort, and package-operation waits can be left while the operation finishes in the background. Removing the selected model asks you to choose a replacement with /model instead of substituting the configured default.

终端将后台启动结果和 shell 输出留在发起它们的会话中，host 失联后可以重新连接，并通过运行中的 host 管理包。程序详情保留完整输出，长段落和草稿正确换行；内容和宽度未变时复用详情渲染。等待 host 响应时界面保持可操作，可以退出等待；包操作则继续在后台完成。调整推理强度会保留命令行选定的模型，不会把该强度带到后来选择的其他模型。删除选中的模型后会提示通过 `/model` 重新选择，不会暗中改用默认模型。
