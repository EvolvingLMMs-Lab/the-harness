The agent's prompts ask for three more things. A program is given about as much to do as the model needs time to write the next one, so that neither the agent stands while the model writes nor the model waits on a long program; every call says how long the last reply took to write and for how much of that no program of the model ran. In practice, a part counts as learned when a run of it ends with everything the next part needs, and what is kept is one skill for one goal, not the whole task as one skill. A node of the tree of reflexes compares the ways to answer its situation (keep out of its way, leave it behind, deal with it) by what each costs the task, and takes the cheapest.

智能体的提示词多了三项要求。每个程序的工作量大约等于模型写下一个程序所需的时间，这样既不会模型在写时智能体站着等，也不会模型反复等一个很长的程序；每次调用都会告知上一次回复写了多久、其中有多久没有模型的程序在运行。练习时，一个部分学会的标准是跑完后带着下一部分需要的所有东西；存下来的是一个目标一个技能，而不是把整个任务存成一个技能。反应树的节点要比较应对当前情况的几种方式（避开、甩掉、处理掉）各自对任务的代价，选代价最小的。
