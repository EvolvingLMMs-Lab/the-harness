A package made for another version of The Harness no longer stops every conversation: the
session host leaves it out, and `harness doctor` and a task that needs it name the package
and say to run `harness install --update`.
<!-- zh -->
为其他 Harness 版本制作的包不再让所有对话失败：session host 会跳过它，`harness doctor`
和需要它的任务会写明是哪个包，并提示运行 `harness install --update`。
