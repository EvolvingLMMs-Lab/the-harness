The core prompt says how to work: build for the situations a thing has to work in, list what it assumes before running it where a failure is costly, test the uncertain assumptions that matter with the smallest test that could prove them wrong, and after a failure repair the part responsible for that kind of situation and look for the same flaw elsewhere.
<!-- zh -->
核心提示词说明了工作方式：为一个东西需要起作用的那些情况而做；在失败代价高的地方运行它之前，列出它的假设；对不确定又要紧的假设，用能证明它错的最小测试去验证；失败之后，修复对这一类情况负责的部分，并在别处寻找同样的缺陷。
