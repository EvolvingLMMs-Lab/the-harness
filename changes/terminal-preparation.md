`harness install --tui` prepares the terminal's dependencies before going offline, without starting a conversation or requiring a model key. It can be combined with package and worker preparation.
<!-- zh -->
`harness install --tui` 可以在离线前准备终端依赖，无需启动对话或配置模型密钥，也可以和包、worker 的准备一起执行。
