The terminal chat is used the way Claude Code is. Shift+Enter, Ctrl+J, Alt+Enter and `\` then Enter start a new line and a paste never sends; the readline keys edit; Up and Down move in a draft before they walk the history, which is kept per directory; Ctrl+R searches it, Ctrl+S stashes, Ctrl+G opens your editor. While it works, the reply appears as it is written, a message you send is queued (Up takes the queue back), Esc stops the turn and keeps what it did, Ctrl+O is the transcript and Shift+Tab the approval level. Commands carry Claude Code's names and aliases (`/clear`, `/resume`, `/config`, `/status`, `/copy`, `/export`, `/keybindings`, `/terminal-setup` and more), an unknown one is answered `Unknown command`, and skills are commands. Keys can be rebound in `keybindings.json` (`/keybindings`), and `terminal.editor_mode = vim` gives Vim keys. Changed: `/continue` now resumes a conversation (a message goes on after a stop), `/host` is `/status`, `/models` is in `/model`, `/reject` is also `/deny`, and the history file is `history.jsonl` (the old `tui-history` is read into it once).

终端聊天的用法和 Claude Code 一样。Shift+Enter、Ctrl+J、Alt+Enter 和 `\` 加 Enter 换行，粘贴不会触发发送；支持 readline 的编辑键；上下键先在草稿里移动再翻历史，历史按目录保存；Ctrl+R 搜索，Ctrl+S 暂存，Ctrl+G 打开编辑器。它做事时回复随写随出，这时发的消息会排队（上键取回），Esc 停下当前回合并保留已做的事，Ctrl+O 是详细记录，Shift+Tab 切换批准档位。命令使用 Claude Code 的名字和别名（`/clear`、`/resume`、`/config`、`/status`、`/copy`、`/export`、`/keybindings`、`/terminal-setup` 等），打错的命令回答 `Unknown command`，技能可以当命令调用。按键可以在 `keybindings.json` 里改绑（`/keybindings`），`terminal.editor_mode = vim` 提供 Vim 键位。有变化的地方：`/continue` 现在是恢复一个对话（停下之后发消息即可继续），`/host` 并入 `/status`，`/models` 并入 `/model`，`/reject` 也可以写成 `/deny`，历史文件改为 `history.jsonl`（旧的 `tui-history` 会被读入一次）。
