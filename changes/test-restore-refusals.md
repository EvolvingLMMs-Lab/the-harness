A model can be tried without keeping anything (`POST /api/app/model/test`: one real call, no entry, no default, no key saved). A backup can be restored from the file a page sends (`POST /api/agent/take` with `restore`), with the same refusals as `harness agent restore`: a wrong passphrase, a file that is no backup, an identity of that id here unless it is replaced. A request the session host refuses says its reason in plain words, with what to do where that is known; the name of a Python exception is no longer part of what a person reads (it is the answer's `code`). Raising today's limit to an amount that is not above it says which amount to give.
