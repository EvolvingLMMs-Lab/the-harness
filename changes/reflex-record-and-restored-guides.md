The record says what a reflex node did not do: a node with a program notes when its situation comes and goes (rule holds, rule over), and, while it holds, why its program does not start (waiting: a node under it answers, its next turn has not come, another node runs before it), once for each reason. A run in which reflexes did not act had left no trace of why. A reflex's program no longer waits for a page to be read: a conversation that goes on in another process starts with no page read, and its reflexes failed at once with "read how routine is used first".

记录里会写下反射节点没做的事：带程序的节点会记下它对应的情况什么时候出现、什么时候结束（rule holds、rule over）；情况成立期间如果程序没有启动，也会记下原因（waiting：下面有节点在应对更窄的情况、它的下一轮还没到、另一个节点先在运行），每个原因只记一次。之前有一局反射没有动作，记录里看不出原因。另外，反射的程序不再要求先读说明页：在另一个进程里接着跑的对话，开始时没有任何说明页被记为已读，它的反射一触发就会报 "read how routine is used first" 并失败。
