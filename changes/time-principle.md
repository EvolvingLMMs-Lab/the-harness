The core prompt has a principle about time beside the ones about building and testing: your reply takes seconds, a program answers at its next step, a reflex at once; before starting something, say what can happen that needs an answer sooner, and have a reflex in place before going where it can happen.

The instruction of a run that learns its environment no longer says how to learn. It says that the run is practice, how much live time there is, that what the library and the environment keep is all the task's runs start with, what counts as learned, and how proposed code is admitted. The six steps are gone, and so are the "Next: ..." lines after each program and "use these first" in the library's listing: what the model is told there is what the library holds and what is pending.

核心提示词在"怎么造、怎么测"的原则旁边加了一条关于时间的原则：你的回复要几秒，程序在下一步才响应，反射立刻响应；开始一件事之前，先说清可能发生哪些需要更快响应的事，并在去到它可能发生的地方之前把反射设好。

学习环境的运行，其指令不再规定怎么学。它只说明：这是练习、有多少实时时间、库和环境保留的东西就是任务运行开局拥有的全部、什么算学会、提交的代码如何被采纳。原来的六个步骤删除；每个程序之后的"Next: ……"提示和库清单里的"先用这些"也删除，那里只告诉模型库里有什么、什么还在等待。
