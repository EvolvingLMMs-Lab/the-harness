A program reads an entry of its library as the library holds it: `library.read(kind, name)` gives a skill's code and its test, or a note's text, so that it can fix the entry under its own name. The library's listing names each entry by its kind and name instead of a file inside the library.
<!-- zh -->
程序可以读出自己库里一条条目的全文：`library.read(kind, name)` 给出技能的代码和测试、笔记的文字，以便在原名下修改它。库的列表改为用种类和名字指一条条目，不再给库目录里的文件路径。
