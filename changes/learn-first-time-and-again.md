The learning page tells a first time from a try again: the first time the agent comes to a step by doing the steps before it, and when it tries the step again it may put that same start back directly, with nothing the earlier steps did not leave. The skill that calls the learned skills in order is run from the start of the task.
<!-- zh -->
学习说明把“第一次”和“重试”分开：第一次到某一步要靠真的做完前面的步骤走到那里；重试时可以直接把同一个起始状况摆回去，但不能多出前面步骤没留下的东西。按顺序串起来的技能要从任务的起点跑一遍。
