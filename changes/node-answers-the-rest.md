Any node of the tree of reflexes may have nodes under it. What a node does itself answers what is in its situation and in none of the nodes under it: they have their turn first, the node's own program or telling comes when none of them is answering, and gives way when one of them begins. So a node no longer has to be turned into a group before something can go under it: `set_reflex(..., under="name")` works under any node whose `when` is a condition, and that node is not set again. The core prompt says to write a node's condition by what is happening to the agent, not by its cause, and to put what is learned later under it.

反射树的任何节点下面都可以挂节点。节点自己做的事，应对的是属于它这种情况、又不属于下面任何一个节点的那部分：下面的节点先轮到，没有一个在应对时才轮到节点自己的程序或上报，下面有节点开始应对时它让位。所以不必先把一个节点改成“组”才能往下挂：只要那个节点的 `when` 是条件，`set_reflex(..., under="name")` 就可以用，而且不用重新设置它。核心提示词说明：节点的条件按 agent 身上正在发生什么来写，不按原因来写；以后学到的东西挂到它下面。
