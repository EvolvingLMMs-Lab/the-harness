What a running program asks of the model is told with every call while one runs, in the same words: when the program has just been started, when a wait ended, when another program ended, when an event came. Before, only the call right after the start carried it; a model that came back to look was told the state and nothing else, and a program that ended beside the running one was followed by "the program ended, answer or write the rest".
<!-- zh -->
模型有程序在运行时，每一次被叫起来都会收到同一段话，说明这个运行中的程序要求它做什么：程序刚启动时、一次等待结束时、另一个程序结束时、有事件到来时都一样。此前只有启动后的那一次带着这段话；模型回来查看时只收到状态，别的什么都没有；而在运行中的程序旁边结束的另一个程序，后面还跟着“程序结束了，回答或者写剩下的部分”。
