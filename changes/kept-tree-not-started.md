When the tree of reflexes acts is the model's to say. A node is started or not: `stop_reflex(names)` stops nodes (they stay in the tree and answer nothing) and `start_reflex(names)` starts them. The tree a library keeps comes into the tree not started when a session begins, where it used to act from the first moment: the model starts it with `start_reflex()` when the agent is where the tree is for. A line of `situations()` that only a node not started answers is not answered.

反射树什么时候起作用由模型决定。节点分“已启动”和“未启动”：`stop_reflex(names)` 让节点停下（仍在树里，但不回应任何情况），`start_reflex(names)` 让它们开始起作用。库里保存的树在新一局开始时会进到树里，但处于未启动状态（以前是开局立即起作用）：模型在合适的时候用 `start_reflex()` 启动它。只有未启动的节点回应的 `situations()` 条目视为没有被回应。
