The core prompt says how to design the tree of reflexes: from the top down, beginning with the widest situations and dividing each into the narrower ones; what several conditions have in common is judged once in the node above them; a deep tree is preferred to a wide one, because a node under another is judged only while that one's condition holds and a wide node still answers the case that was not listed; a new node goes under the narrowest node whose situation it falls in.
<!-- zh -->
核心提示词说明了反射树怎么设计：从上往下，先定最宽的情况，再把每个分成更窄的；几个条件里共同的部分只在它们上面的节点里判断一次；宁可树深不要树宽，因为挂在别的节点下面的节点只有上面那个条件成立时才被判断，而且宽的节点能接住没列出来的情况；新节点挂到它所属的最窄的那个节点下面。
