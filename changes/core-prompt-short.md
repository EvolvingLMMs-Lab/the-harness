The core prompt is less than half as long. It keeps what every reply needs: how to reply, how to work, and one line for each call. The details of the tree of reflexes (every setting of a node) and of units (waits, what the model is told and in what order, units of its own, who has the environment) are in two pages that a program reads on demand, `guide("tree")` and `guide("units")`. A page that was read is given again after a summary of the conversation. `reflex_method()` still works and returns `guide("tree")`. The other sections are brought to the same standard. The request for a reflection after an episode (every embodiment but a robot, whose request is unchanged) asks for a note, a memory entry or a skill and no longer for a reactive helper: the nodes of a tree are kept from the tree the agent set. The library section gives `setup` in the signature of `library.propose` and no longer names a `tree` call. The checklist section has no example task. The section on world memory, which no setting could switch on and whose calls do not exist, is removed.

核心提示词缩短到不到原来的一半，只留每次回复都用得上的内容：怎么回复、怎么工作、每个调用一行。反射树的细节（节点的每一项设置）和单元的细节（等待、会被告知什么及顺序、自己启动的单元、谁占用环境）放进两页按需读的说明里：`guide("tree")` 和 `guide("units")`。读过的页在对话被摘要之后会重新给一遍。`reflex_method()` 仍然可用，返回的就是 `guide("tree")`。其余几段按同一标准整理：一轮结束后的复盘请求（机器人以外的环境；机器人的请求不变）只要笔记、记忆或技能，不再要“反应式辅助”，反射树的节点从 agent 设好的树里保留；学习库那一段在 `library.propose` 的签名里补上了 `setup`，不再提并不存在的 `tree` 调用；清单那一段不再带具体任务的例子；讲世界记忆的那一段没有任何设置能打开，提到的调用也不存在，已删除。
