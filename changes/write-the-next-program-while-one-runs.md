While a program runs, the model is told first to write and send the program for what comes after it (with after()), and only then to look in on the running one: the agent goes on at once when a program ends instead of standing while the next one is written.
<!-- zh -->
程序运行时，先告诉模型写好并发出下一步的程序（用 after() 排在后面），然后才是回来查看正在运行的程序：一个程序结束时，智能体立刻接着做，而不是站着等下一个程序写完。
