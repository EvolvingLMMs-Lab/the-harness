A node of the tree of reflexes is set together with its trial, and the method of designing a tree is read when the tree is made. `set_reflex(..., test=...)`: `test` is a function that brings the node's situation about (it is run at once and `set_reflex` returns what it showed: whether the node had its turn, how long that took, whether its program left the situation over) or a sentence saying why the situation cannot be brought about here; the node acts in either case. Before the first node of a run the model reads `reflex_method()`, the page on how a tree is designed and tried, which the core prompt no longer carries; `set_reflex` is refused until then, and the page is given again after a summary. The first time a node's program does its work outside its trial, the model is told what it did (`REFLEX_ACTED`). The tree's line says how many nodes were not tried or did not work in their trial. `runtime.reflex_trials = "optional"` turns this off. Breaking: `set_reflex` without `test` is refused unless that setting is `optional`; what a library entry sets is not affected.

反射树的节点现在和它的试验一起设置，设计树的方法在建树时才读。`set_reflex(..., test=...)`：`test` 是一个把节点的情况造出来的函数（当场运行，`set_reflex` 返回试验显示的结果：节点有没有轮到、花了多久、它的程序有没有让情况过去），或者一句话，说明这个情况在这里为什么造不出来；两种写法节点都立刻生效。一局里设第一个节点之前，模型要先读 `reflex_method()`，也就是讲树怎么设计和试验的那一页，核心提示词里不再带这部分；没读过时 `set_reflex` 会被拒绝，对话被摘要之后这一页会重新给一遍。节点的程序第一次在试验之外把事办成时，会告诉模型它做了什么（`REFLEX_ACTED`）。树的那一行会说明有几个节点没试过、几个在试验里没起作用。`runtime.reflex_trials = "optional"` 关闭以上全部。不兼容之处：除非把这个设置改成 `optional`，不带 `test` 的 `set_reflex` 会被拒绝；库条目设置的节点不受影响。
