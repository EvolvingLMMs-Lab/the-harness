What a reflex is and says for itself changes. Every node the model sets does something: `set_reflex` without `do=` is refused, a node above others has a program too (the fallback of its whole situation, for what no node under it answers or solves), and the name of an event is for watching what a program is for, not an answer to a situation. Each node says what the model hears of it: `tell=` ("never", "first" by default, or "later", "next", "now" for every time, at that place in the model's queue) for work done, and `tell_failed=` ("now" by default) for work that was not done and that nothing else took. A trial (`test=`) is no longer required, and a sentence in place of a trial is no longer accepted; instead a node's condition is judged once when it is set, and one that raises is refused. A tree proposed for the library is kept as its nodes stand in the tree. `runtime.reflex_trials` is now `runtime.reflex_method`. Two faults are fixed: a node that tells and ends what runs (`do="EVENT", ends=True`) no longer ends the answer of a node under it, and a node under another has done its work when its own condition or one above it no longer holds.

反射节点是什么、自己说明什么，有了变化。模型设的每个节点都要做点什么：不带 `do=` 的 `set_reflex` 会被拒绝，上面带着其他节点的节点也要有程序（它是整个处境的兜底，管下面没有节点应对或没解决的部分），事件名只用于盯着某个程序的目的，不是对处境的应对。每个节点自己说明模型会听到什么：`tell=`（"never"、默认的 "first"，或每次都告诉的 "later"、"next"、"now"，对应模型队列里的位置）管事办成时，`tell_failed=`（默认 "now"）管事没办成又没有别的节点接手时。试验（`test=`）不再是必须的，也不再接受用一句话代替试验；改为设节点时把条件当场判断一次，抛出异常的被拒绝。提交给库的反射树按节点在树里的样子收下。`runtime.reflex_trials` 改名为 `runtime.reflex_method`。修了两处故障：告诉模型并结束正在运行的东西的节点（`do="EVENT", ends=True`）不再把它下面节点的应对结束掉；挂在别的节点下面的节点，在自己的条件或上面某一层的条件不再成立时就算完成。
