An agent identity can be taken with you. `harness agent share ID --to PLACE` sends its persona,
avatar, skills and reactions as a package the way `harness share` sends a library (a GitHub
repository it creates is private), after printing every text that becomes public; local places
become names, the groups its reactions name become placeholders, and the private key, channel
credentials and model keys never go; `--card` writes a Character Card V3. `harness agent adopt`
makes a new identity with a new key from a shared one or a card: adopted skills stay proposed
until their own tests pass here, adopted reactions start disabled. `harness agent backup` and
`restore` move a whole identity, its key, memory and channel credentials included, in a file
encrypted with a passphrase; `harness agent retire` stops it on the old computer, where opening
it then says it has moved. `harness agent import openclaw|hermes` brings persona, memory and
skills over without channel tokens. Conversations of the terminal chat and the app from before
identities are listed under `default` as earlier chats. New docs: the resident agent, and
taking an identity with you.

agent 身份可以带走了。`harness agent share ID --to PLACE` 像 `harness share` 发送学习库那样，把它的人设、头像、技能和反应作为包发出去（新建的 GitHub 仓库是私有的），发送前打印所有将公开的文字；本机位置换成名字，反应里提到的群换成占位符，私钥、渠道凭据和模型 key 永远不带；`--card` 导出 Character Card V3。`harness agent adopt` 用分享的身份或角色卡新建一个有新密钥的身份：领养的技能在自己的测试在本机通过之前一直是提议，领养的反应一开始是停用的。`harness agent backup` 和 `restore` 用口令加密的文件搬运整个身份，包括密钥、记忆和渠道凭据；`harness agent retire` 在旧电脑上停下它，之后在那里打开会提示它已搬走。`harness agent import openclaw|hermes` 带来人设、记忆和技能，不带渠道 token。身份出现之前终端对话和 app 的对话作为早期对话列在 `default` 下。新文档：常驻的 agent，带走身份。
