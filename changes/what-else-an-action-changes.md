The core prompt and the refusal of an unchecked action now ask for one more kind of `expect`: what else the action changes besides the thing it acts on, and the state the agent is in when it is done, from which it has to be able to go on.
<!-- zh -->
核心提示词和“未检查就动作”的拒绝文字多要求一类 `expect`：这个动作除了它要改的东西之外还会改变什么，做完以后 agent 处在什么状态；它必须能从那个状态接着做下去。
