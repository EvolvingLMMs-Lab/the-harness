A reflex whose condition reads the state is judged every period also while no program runs: the environment's state is read then too, as the environment changes by itself. It was read only while a program ran, so a node such as "come up for air" went unjudged while the model thought between programs.
<!-- zh -->
条件读状态的反射节点在没有程序运行时也每个周期判断：这时也读环境状态，因为环境会自己变化。以前只在有程序运行时读，所以像“没气了就上浮”这样的节点在模型两段程序之间思考时得不到判断。
