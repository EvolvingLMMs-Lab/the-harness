The core prompt describes how to work as one loop, from what an action is for to what is observed of it, and the agent is told more at the moment it matters. A program has to say what it is for (`until(condition)`, or `until(None)` for one that only reads) or it is not started; `runtime.purpose = "optional"` turns that off. A reflex can end what its program interrupts instead of resuming it (`set_reflex(..., ends=True)`). An event is told with the how-manieth of its kind in the run it is; a running unit with which reflexes paused it and how often; the tree with how many nodes never had their turn. A wait with a time lasts that long (it was cut to `runtime.longest_wait_seconds`, which now applies only to a wait without a time). Everything told and replied is kept in `record.jsonl` in the run's directory, and the text that follows a compaction names it. The plan (`plan`, `step_done`) is shown to the model again when it has not touched it for ten calls. An environment can name the part of its state that is the agent's situation (`"situation"` in its profile): the model is told the first time it takes a new value. `review(code, purpose)` has a sub-agent that has not seen the conversation read code.

核心提示词把“怎么干活”写成一个环：从一个动作是为了什么，到观测到它做成了什么；并且在用得上的时刻多告诉 agent 一些事实。程序必须说明自己是为了什么（`until(condition)`，只读的程序写 `until(None)`），否则不会启动；`runtime.purpose = "optional"` 可关闭这一要求。反射可以让被它的程序打断的东西结束而不是恢复（`set_reflex(..., ends=True)`）。事件带上它是这一局里同类的第几次；在跑的单元带上被哪些反射暂停过几次；反射树带上有几个节点从没轮到过。写了时间的等待按所写的时间（以前会被截到 `runtime.longest_wait_seconds`，现在这个设置只用于没写时间的等待）。告诉模型的和模型回复的全部内容保存在运行目录的 `record.jsonl` 里，压缩之后的那段话会给出它的路径。计划（`plan`、`step_done`）在模型十次调用没碰它时会重新给它看。环境可以在自己的说明里指出状态中哪一项表示 agent 的处境（`"situation"`）：这一项第一次出现新值时会告诉模型。`review(code, purpose)` 让一个没看过对话的子代理来读代码。
