An urgent event or the end of a unit no longer drops the reply the model is writing: it ends a wait and is told first with the next call, and the program in the reply runs, checking with expect what it relies on. Only a message of the user still sets the reply aside. A program written for half a minute was thrown away by the first event that came meanwhile.

紧急事件或单元结束不再丢掉模型正在写的回复：它会结束等待，并在下一次调用时最先告诉模型；回复里的程序照常运行，并用 expect 检查它依赖的条件。只有用户的消息仍会作废正在写的回复。以前写了半分钟的程序，会被这期间到来的第一个事件扔掉。
