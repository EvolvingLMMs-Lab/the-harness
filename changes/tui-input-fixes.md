In the terminal chat, typing in a prefilled field (a setting, a project folder) or in a
message kept after a cancelled start goes on from its end, and cancelling the environment choice of a new conversation, or a start
that fails, no longer sends the next messages to the conversation that ended. Enter on an
empty reason refuses without one, Ctrl+O details keep program output on separate lines, and
`/models` opens a model list saved with a mistake so it can be corrected.
