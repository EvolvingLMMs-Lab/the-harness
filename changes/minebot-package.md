minebot: minor
---
A new package, `minebot`: a bot body for Minecraft: Java Edition servers. The agent joins a server you name as a player (`minebot.host`, offline or with a Microsoft sign-in), runs its code on the body, keeps routines and sets reflexes; `harness --workspace minebot` opens it in a conversation, and `harness minebot run` keeps a learning session in a folder of its own. The package ships and downloads nothing of the game: it joins a server that is there, and an optional game window is your own game with one mod. Node and the body's libraries are installed on first use.
