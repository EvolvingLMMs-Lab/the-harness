Where an environment names the place it is described at (its profile: `situations_source`, the start of the addresses), `situations(...)` is refused until a program before it has fetched a page from there for the situation the agent is in; the refusal carries the environment's own sentence. Before, that sentence came only with a refusal, which a model that gave its list at once never met.
<!-- zh -->
环境可以写明它自己的说明在哪里（profile 里的 `situations_source`，地址的开头）。这时 `situations(...)` 会被拒绝，直到更早的某个程序已经为智能体当前所处的情况从那里读过一页；拒绝里带着环境自己的那句话。此前这句话只随拒绝出现，而一上来就给出清单的模型根本遇不到它。
