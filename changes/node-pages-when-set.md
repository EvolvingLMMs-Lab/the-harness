A node of the tree of reflexes is held to the pages of what it calls when it is set, not when it acts. set_reflex refuses a node whose functions call a skill call with an unread page, and hands the code they hold or name for the environment to the environment's own page check; a node set from the library when a conversation starts was checked when it was written. When a node acts nobody reads, and nothing waits for a page then.

反射树的节点在设置时就按它调用的东西检查说明页，节点执行时不再检查。set_reflex 拒绝一个调用了未读说明页的 skill 调用的节点，并把节点里交给环境执行的代码（函数里写着的或引用的字符串）交给环境自己的说明页检查；对话开始时从笔记库加载的节点，在写下它时已经检查过。节点执行时没有人在读，也就不再等说明页。
