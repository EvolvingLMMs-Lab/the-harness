---
title: Let it learn an environment
---

Learning writes into an explicitly bound library. It is distinct from persistent identity and personal long-term memory.

```bash
harness run "Learn this project workflow" --folder . --learn 10 --library ./task-library
harness library show ./task-library
```

Retain observations, action receipts and failures. Executable proposals require trusted verification and activation at a safe boundary; a proposal is not an active capability. Missing compatible fixtures do not count as successful verification. Record task budgets separately from learning minutes.
