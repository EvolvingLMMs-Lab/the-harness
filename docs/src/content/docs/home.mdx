## How it acts

<CardGrid>
  <FigureCard layer={3} title="Any language model">
    Plans and writes programs at decision points, and thinks while they run. Swap the model in one line of configuration.
    [Learn more](/docs/concepts/harness/).
  </FigureCard>
  <FigureCard layer={2} title="Programs and learned policies">
    Programs compose skills and tools; a learned policy takes over what code cannot express.
    [Learn more](/docs/extend/skills/).
  </FigureCard>
  <FigureCard layer={1} title="Reflexes">
    Guards and controllers the model writes run on every control step, so a slip is caught before the model hears of it.
    [Learn more](/docs/extend/reactive-rules/).
  </FigureCard>
  <FigureCard layer={0} title="A fixed safety layer">
    Every command passes limits that nothing learns or rewrites, whoever wrote it.
    [Learn more](/docs/concepts/harness/#how-a-task-runs).
  </FigureCard>
</CardGrid>
