**The Harness** is agentic control for anything that acts. You tell an agent what to do
in your own words; a language model plans and writes short programs, and The Harness
runs them in an environment the agent can see and act in, while you watch, add a message
or take over.

```bash
pip install the-harness
harness
```

`harness` opens a conversation in your terminal. The first time, it asks which model to
use and for its key; then type a task. The agent thinks while it acts: between model
calls, its programs, skills and reactive rules keep working, and what it learns along
the way (notes, tested skills, rules) applies in the same run.

## Where it works

The core is small. What the agent works on comes in packages, installed by themselves
the first time a task needs them:

| Environment | Package |
|---|---|
| Your computer: apps and windows, or a display of its own | `computer` |
| Websites, in a background browser | `browser` |

Any model works: hosted ones through OpenRouter, OpenAI, Anthropic and other providers,
or a model you run yourself.

## Commands

| Command | |
|---|---|
| `harness` | talk with the agent in the terminal |
| `harness run "task"` | do one task and print the answer (`-p`), or every event (`--json`) |
| `harness run rpc` | drive a conversation with JSON lines, from another program |
| `harness install`, `list`, `remove` | packages |
| `harness library` | what the agent learned |
| `harness replay` | a run again in the terminal |
| `harness doctor` | what this computer has and lacks |
