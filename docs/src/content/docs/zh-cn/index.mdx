**The Harness**：自主控制，让智能付诸行动。你用自己的话告诉 agent 要做什么；语言模型做规划、写短小的程序，The Harness 在一个 agent 能看见、能操作的环境里运行这些程序，你可以在一旁看着、补充一条消息，或者自己接手。

```bash
npm install -g @lmmslab/harness   # 或： pip install the-harness
harness
```

`harness` 在你的终端里打开一个对话。第一次运行时，它会询问用哪个模型以及它的 key；然后输入一个任务。agent 边想边做：在两次模型调用之间，它的程序、skill 和反应规则会继续工作；它在过程中学到的东西（笔记、测试过的 skill、规则）在同一次运行里就会用上。

## 它能在哪里工作

pip/npm 只安装小巧的 core。环境以包的形式交付，在任务第一次需要时自动安装：

| 环境 | 包 |
|---|---|
| 你的电脑：应用和窗口，或一块独立显示屏 | `computer` |
| 网站，在后台浏览器里 | `browser` |
| 项目文件和进程，在绑定的工作目录里 | `workspace` |

任何模型都可以用：通过 OpenRouter、OpenAI、Anthropic 等 provider 使用托管模型，或者用你自己运行的模型。

## 命令

| 命令 | |
|---|---|
| `harness` | 在终端里和 agent 对话 |
| `harness run "task"` | 做一个任务并打印答案（`-p`），或打印每个事件（`--json`） |
| `harness run rpc` | 从另一个程序用 JSON 行驱动一个对话 |
| `harness install`、`list`、`remove` | 包 |
| `harness library` | agent 学到的东西 |
| `harness replay` | 在终端里重放一次运行 |
| `harness doctor` | 本机已有什么、缺什么 |
