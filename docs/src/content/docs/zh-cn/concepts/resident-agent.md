agent 身份（[保留 agent 身份](/docs/zh-cn/use/identities/)）不是一个打开、关掉的 app。装好以后它就一直在工作：看着你给它接上的地方，应对那里发生的事，在预算内做自己的事，并且学习。app、终端和聊天渠道只是和它说话、看它的方式；关掉它们什么也不会改变。

## 一直在工作

会话主机把每个身份的**生活**作为常驻服务来运行。登录项在你登录时启动主机（`the-harness host install`），只要还有一个身份在生活，主机就不退出。终端里的 `the-harness`、`the-harness agent`、Python API、app 和聊天渠道都接到同一个生活上。

它的对话：

- **主对话**是你和它的私聊。你在聊天渠道里和它的私聊也是这同一个对话；每条消息标出来自哪个渠道，回答也回到那里。
- **每个接上的地方**各是一个对话：项目文件夹、浏览器、桌面、渠道账号，渠道里的每个群各一个。那里发生的事、反应、动作和结果都记在其中。
- **新对话**为一件事单开一个对话。

来自所有前端的消息按到达顺序进同一个队列。不同对话的回合并行；同一个对话里，下一回合等上一回合。桌面同一时间只能由一个对话使用，其他对话要等它，显示 `waiting: desktop`。**暂停**时模型和它的工作都停下，地方保持连接，事件照常记录；**退出**时，进行中的动作能取消的结果为 *cancelled*，不能取消的为 *unknown*。重启以后每个对话从记录接着走；比 `agent.stale_hours`（6）更早的事件合成一份摘要交给模型，由它判断哪些还值得回应。

## 一棵时刻在判断的反应树

每个身份有一棵**反应树**（身份文件夹里的 `reactions.json`）。只要有变化或者到了某个时间，它的生活就从根判断这棵树，不管有没有任务在跑、有没有人问、还有没有预算。节点有三部分：

| 部分 | 是什么 |
|---|---|
| 条件 | 何时接手：某个地方的事件及其字段、一个结果、此刻的事实（`battery`、`owner_active`、`working_in`、`asleep`），或者这些的 all / any / not。情境还要说明何时结束。 |
| 应对 | 五种之一：调用技能、叫醒模型、停下、提醒你、什么都不做。 |
| 位置 | 它挂在哪个节点下以及在那里的次序。前面的节点会打断后面节点正在做的事。 |

每个身份自带三个节点，可以停用，不能删除：*被点名或冲着它来 → 叫醒它*、*动作结果为失败或未知 → 叫醒它*、*需要批准 → 提醒你*。你描述一个即使它被动时也必须发生的反应（"电量低于 20% 就停下"），它会立刻成为节点，标为*主人添加*，挂在最贴切的分支下。你说的其他话是偏好，记进记忆。目标、计划和做事的方法从不进树；做事的方法是技能。

## 叫醒模型

只有客观条件才会叫醒模型：

- **发生在它身上、需要理解的事**：你说话、有人点它的名、动作被拒绝或失败、树应对不了的事。
- **它自己想做的事到期**：它留下的意图（在某个时间、若干分钟后，或某个事件发生时）、日历上的条目、它选的练习、某个地方积压的事件（20 个，或最早的已有 4 小时）。

醒来后，它决定要不要做事、做什么；结束前留下意图和应当再次叫醒它的条件。除此之外模型不运行，所以没有要想的事时，身份不花钱。

## 日历

每个身份有一个普通的日历。你和它都可以往上放东西：目标、任务、提醒、它给自己的安排，一次、每天或每周。日历也显示发生过的事：每个回合以及谁发起的（你，或它自己）、树的每次反应、它们的结果、安全层拒绝了什么、它什么时候在睡觉。计划好的条目到时间就叫醒它。放在已经过去的时间上的条目从来没有到期过：它留在日历上，记为错过，不会叫醒任何东西。`the-harness calendar -q TEXT` 按文字查找条目。你移动或删除它安排的事，或者说"这类事别做了"，都会成为私人记忆，影响它以后的判断。每天早上 6:00 以后，一份摘要（做了什么、学了什么、花了多少、什么在等你）会进主对话和 `DREAMS.md`。

它在哪里可以主动做事由你决定：`agent.proactive`（`on`、`learn_only`、`off`）、"暂停主动"，以及每个地方的 `spaces.<地方>.proactive`（`off`、`learn`、`do`；默认项目文件夹和浏览器为 `do`，桌面为 `learn`，聊天群为 `off`，除非你在那个群里给了它目标）。

## 谁能指挥它：安全层

每个动作执行前都经过一个由固定规则组成的**安全层**。它不是 agent 的判断，也不会被学习改掉：

- 你在用桌面时，它在桌面上的输入被拒绝；它不和你抢鼠标。
- 发送、发布、付款、删除和不可撤回的步骤，只有经你批准才执行；登录留给你。什么算发送由那个地方声明（在提问的对话里回复不算发送）。
- 权限来自回合的来源，从不来自提示词里说了什么：你（你绑定的渠道账号、本机前端）、它自己发起（低一档，只在允许 `do` 的地方）、其他所有人（只限他们所在的对话，从不涉及你的电脑、文件或账号）。一个回合取其所有来源中最低的权限。

拒绝以结果 *refused* 加原因交给 agent；之后怎么做由它自己判断，日历会记下来。

## 批准和通知

需要批准的动作会得到一个短码，比如 `A7`：主对话和它所在的对话里各一张卡片，一条系统通知，以及你在已绑定渠道私聊里的一条消息，你在那里回 `A7 approve` 或 `A7 reject`。最先到的回答生效。`approvals.timeout_minutes`（30）分钟内无人回答，结果为 *cancelled*，从不当作完成。系统通知只用于四种事：批准、花费到达上限、动作失败或结果未知、渠道登录过期。

## 学习

学习默认开启。技能是兼容 `SKILL.md`（[agentskills.io](https://agentskills.io)）的文件夹，还带着程序和它的测试。每个技能有证据等级：*提议*、*自测通过*、*回放通过*、*实际有效*（用了 5 次至少 80% 完成，或在有评分的环境里分数更高）。在动作有外部后果的地方，新技能只能由模型手动调用，树要等它实际有效后才调用。

一个对话在回合结束后安静 10 分钟，后台回看最多提议一样东西：一个技能（先跑它自己的测试）、一个反应、一条记忆或一次练习。每天 0:30 它合并重复的，把 30 天没用的归档，把手动做过好几次的事变成技能，并把这一天写进 `DREAMS.md`。`learning.mode` 决定方式：`on`（立即生效，可撤销）、`review_first`（等你审）、`frozen`（只用不学）、`off`。

## 花费

每个身份有每日预算 `agent.daily_budget`（$2），0:00 重置，其中 `agent.reserve`（$0.50）留给你的事：你的消息、点名和你批准之后的工作。它自己的事用剩下的部分，按今天剩下的钱和时间分配。用完了它就睡觉：树照常运行，事件照常记录，你仍然可以叫醒它，其他事等到 0:00。见[限制身份的花费](/docs/zh-cn/use/spending/)。

## 四种前端

每件事在每种前端里都有入口：

| 事 | App | 终端（`harness`） | 命令行 | Python |
|---|---|---|---|---|
| 对话 | 左栏 | `/sessions` | `the-harness sessions` | `Agent.chats()` |
| 身份 | 左栏底部 | `--identity` | `the-harness agent new/use/list/rename/delete` | `Agent(id)` |
| 记忆、反应、学到的东西 | 设置 › 学到的东西 | `/library` | `the-harness library` | `Agent.memory()`、`Agent.reactions()` |
| 批准 | 批准卡片、通知 | `/approve`、`/reject` | `the-harness sessions approve` | 会话接口 |
| 渠道 | 设置 › 连接器 | `/channels` | `the-harness channels` | `Agent.channels()` |
| 日历 | 左栏的日历 | `/calendar` | `the-harness calendar` | `Agent.calendar()` |
| 用量 | 标题栏、设置 › 用量 | `/usage` | `the-harness usage` | `Agent.usage()` |
| 常驻服务 | 托盘菜单 | `/host` | `the-harness host install/uninstall/stop` | `Host` |
| 带走 | 设置 › 数据 | — | `the-harness agent share/adopt/backup/restore/retire` | `Agent.share()` 等 |

把身份搬到另一台电脑、分享和备份，见[带走身份](/docs/zh-cn/use/take-it-with-you/)。
