---
title: 让它学习一个环境
---

学习会写入显式绑定的 library；它不等同于持久身份或个人长期记忆。

```bash
harness run "Learn this project workflow" --folder . --learn 10 --library ./task-library
harness library show ./task-library
```

任务应保留原始观察、动作回执和失败。可执行提案需要可信验证器检查后，在安全边界激活；提案存在不等于能力已生效。缺少适用 fixture 时不能声称验证通过。在你允许（`learning.admission = "own_test"`）且环境不是物理环境时，宿主会在两个程序之间运行提案自带的测试，通过的作为自测条目接纳，见[代码如何被接纳](/docs/zh-cn/learn/while-working/#代码如何被接纳)。预算限制与学习的分钟数分别记录。
