你从来不必等 agent 做完。消息会立即送到它那里，你可以让它在下一步停下，也可以随时把电脑拿回来。所有前端的做法都一样；下表列出 app 和终端里的操作方式。

| 想要 | 在 `harness` 里 | 在 app 里 |
|---|---|---|
| 告诉它一件事 | 输入一条消息 | 输入一条消息 |
| 暂停 | **Esc**（或 **Ctrl+C**） | **停止** 或 **Esc** |
| 继续 | `/continue` | **继续** |
| 批准或拒绝一步 | 输入框上方的选项（按数字，或 ↑ ↓ 加 Enter） | 卡片上的按钮 |
| 自己使用电脑 | | **接管**，然后 **交还** |
| 结束对话 | `/end` | 开始一个新对话（旧的留在列表里） |

## 在它工作时告诉它一件事

消息对模型来说是新情况，它会立即收到：

- **模型正在写回复时**，这条回复会被放在一边，模型带着你的消息重新被询问。
- **程序正在运行时**，程序继续运行，模型立即带着你的消息被询问。它的回答决定程序怎么处理：
  - 让程序跑完，然后带着程序的结果再被询问一次；
  - 在旁边运行一些不需要屏幕或控制权的东西（告诉某个子 agent、更新计划、做一次计算），程序继续运行；
  - 或者让程序在下一步停下，改做别的事。
- **它启动的任务和子 agent** 会继续运行，直到 agent 通知或停止它们。

所以"用便宜的那趟航班"会改变计划，而不会丢掉 agent 正在读的页面；而"停下，账号不对"会让它在下一步停下。

## 模型什么时候被调用

模型的每一次调用都是一次**思考**，由下面某一种情况触发：

| 什么时候 | 两个程序之间 | 程序运行时 |
|---|---|---|
| 对话开始 | 是 | |
| 你发了一条消息 | 是 | 是，立刻 |
| 一个事件或错误上报给模型 | 是 | |
| 一个程序结束，或一条回复没法用 | 是 | |
| 一个程序开始（`think_while_acting = "on"`） | | 是：它规划下一步 |
| 有新情况出现（`"on_events"`，默认） | | 是 |
| 隔了若干秒没有调用（`"periodic"`） | | 是 |
| episode 结束 | 一次简短的反思，可能提出学到的东西 | |

程序运行时，同一时刻最多只有一次思考在进行，新的触发等它结束；你的消息会作废还没用上的回复。一条回复可以运行一个程序、在程序旁边运行一段不需要屏幕和控制的代码、启动或通知一个子 agent、停下程序、记住一件事、提出一个 library 条目、回答你、等程序的结果，或者结束。`config.toml` 里 `[model]` 下的 `think_while_acting` 决定 agent 边想边做的频繁程度。

## 暂停和停止

`harness` 里的 **Esc**（或 app 里的 **停止**）让正在运行的程序在下一步停下：不再有任何操作，在你输入 `/continue`（**继续**）或发送消息之前，模型不会再被调用。暂停期间发送的消息会替换掉还没开始的程序。

**End** 结束对话。如果是 benchmark 的一次运行，环境随后会给这个 episode 打分。

## 逐步审批

敏感步骤总会等你：目标涉及凭据、付款、发送、删除或无法撤销的操作的步骤。你允许或拒绝它，只对这一步有效。在 `[approvals]` 下设置 `ask = "programs"`（app 里的 **动手前先问我**）时，每个程序也要等：agent 会在程序运行前把它展示出来，你可以批准，或者附上理由拒绝，模型会读到理由。被拒绝的步骤不会运行（[权限](/docs/zh-cn/configure/permissions/#审批)）。

## 接手

当 agent 在你自己的桌面上工作时：

- **接管** 会在你使用电脑时暂停它。**交还** 把电脑还给它，agent 会先重新看一遍屏幕再继续。
- **你的操作优先。** 你使用鼠标或键盘时，它的步骤会等到你停下，然后它重新看一遍。如果你把自己的某个窗口切到前台，它会像 **接管** 之后那样停下，在你交还之前不会把屏幕拿回去。
- **要立即停止它**，把指针推到屏幕的一个角落。

后台浏览器、后台应用和独立显示屏从不使用你的鼠标和键盘，所以没有什么需要拿回来：你使用电脑的时候，agent 照常工作。

## 它何时可以使用你的鼠标和键盘

agent 是否可以使用真实的鼠标和键盘、可以在哪些应用里使用、是否要先询问，是一项有多个级别的设置，从从不到总是，并且可以针对应用、窗口和操作类型设定规则。[权限和隐私](/docs/zh-cn/configure/permissions/)介绍了这些设置；在 `harness` 里用 `/settings`，或在 app 的 **Settings** 里修改它们。

## 在时间轴上

你的消息在时间轴上标为 `●`，agent 的消息标为 `○`，暂停标为 `‖`，结束标为 `■`。回复被放在一边或没有被使用的模型调用会画得颜色较浅，所以你可以看出你的消息改变了什么。
