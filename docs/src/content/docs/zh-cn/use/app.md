应用是一扇窗口，看的是住在 session host 里的那个 agent。它从[桌面应用](/docs/zh-cn/getting-started/desktop-app/)打开；用 pip 安装的，运行 `harness app`，它会打印一个地址，在浏览器里打开。关掉窗口不会让 agent 停下；终端对话（`harness`）里看到的是同一批对话。

## 第一次打开

第一次打开时，窗口上盖着一层欢迎页。它列出这台电脑上能当模型用的东西：已经登录的 agent（用你自己的订阅，不需要 key）、环境里找到的某个提供商的 key、这台电脑上的模型，或者你现在填的一个 key。用鼠标或方向键选一个，点 **试一下**（或按 Enter）：它会被问一个词，答得出来才保存。**稍后再选模型** 可以先进去看看；这时输入框上方会说明还没有选模型。

空的对话里有几句可以直接用的话。点一句，或者自己输入。

## 窗口

| 位置 | 内容 |
|---|---|
| 左边 | **新对话**、**日历**、对话列表、**设置**，最下面是正在使用的身份（点它可以切换） |
| 中间 | 对话：顶部是标题和状态，然后是记录、打开时的时间线、输入框和状态条 |
| 右边 | 工具栏：当前对话的上下文、终端、浏览器、文件和改动，每一项在侧面板里打开成一个标签页 |

每个图标都有名字：把鼠标停在上面，或者用 Tab 移过去。

## 对话

- **回复边写边显示。** agent 使用工具时，每个动作在发生时显示出来，并带着它的结果；之后它们收成一行（几个动作、各是什么结果、用了多久），点开是这些动作，每个动作再点开是给它的内容和返回的内容。
- **思考内容** 在模型思考时显示在回复上方。**设置 › 通用 › 显示思考内容** 可以把它隐藏。
- **Enter** 发送，**Shift+Enter** 换行。用输入法组字时，Enter 归输入法。
- **停止**（方形按钮，或 Esc）停下这一回合。已经做完的保留。
- **队列。** 它做事时你发的消息在输入框上方排队。每一条都能编辑、删除或立即发送。有消息在排队时按停止，队列会被按住并展开；点 **继续** 让它接着走。队列由 host 保存：重启后还在，在每个窗口和终端里都一样。
- **草稿。** 输入了还没发的内容跟着它的对话：去看别的对话或重启应用，回来还在。
- **阅读位置。** 回到一个对话时回到你上次读到的地方。离开时停在底部的对话会继续跟着新内容；**回到最新** 带你回到底部。
- **附件。** 把文件拖到对话的任何位置、粘贴一张图片，或者用 **+**。它们随你的下一条消息发出。
- **发过的消息。** 在空的输入框里按上、下键，调出你在这个对话里发过的消息。
- **查找。** Ctrl+F 在记录里查找；Enter 和 Shift+Enter 跳到下一个、上一个，Esc 关闭。

### 它问你的时候

付款、发送、删除以及其他必须由你决定的步骤之前，对话里会出现一张卡片问你：*要继续吗？* 按 **1** 选 *是*，按 **2** 选 *否，并告诉它换个做法*（会出现一行让你写换成什么做法），或者按 **Esc** 拒绝。到时间没人回答的请求算取消，不会当成完成。左栏顶部的铃铛带你去等你的那个对话。

### 一个回合失败的时候

一张卡片说明哪里出了问题、该怎么办，并带着 **重试**（把这一回合的那句话再说一遍）、**换模型**（只换这个对话）、**打开日志**（host 日志的末尾）和 **复制错误**。

## 一个对话用的模型

模型选择器在输入框旁边。它把这里已经设好的模型列在同一个列表里（这台电脑上已登录的 agent、提供商的 key、本机模型），并且**只**改**这个对话**的模型；对话进行到一半时会先问你，因为新模型要把整个对话重新读一遍。**设置 › 模型** 改的是新对话默认使用的模型。

## 状态条

在输入框下面：agent 会先问你哪些事（点它可以改；所有对话共用）、上一次模型调用读了多少、这个对话在哪里做事、它的模型，以及今天花了每日额度里的多少。

## 对话列表

- **搜索**（放大镜，或 Ctrl+Shift+F）在标题和说过的话里找。
- **置顶** 让一个对话留在最上面。**归档** 把它从列表里收走；列表上方的 **已归档** 显示归档的对话，在那里可以阅读和取消归档。
- **改名** 和 **删除**（会先问你）。

这些都在对话那一行的菜单里（行上出现的按钮，或鼠标右键）。主对话不能归档，也不能删除。

## 日历

左栏的**日历**显示它做过什么、接下来有什么安排：你交代的事、它主动做的事、它学的东西、运行过的反应，以及它什么时候在睡觉。每一类画得不一样，每件事上都有一个记号，标明它是怎么结束的。

- **视图。** 日、周、月、年，用右上角的按钮或下面的按键切换。点某一天的数字打开那一天；左边的小月历用来翻到别的日期。
- **新建。** 点一个空的时间格，或者拖出一段时间，在小框里写标题，按 Enter 保存。**更多选项**打开完整的表单：种类（任务、提醒或目标）、全天、开始、结束、重复、备注。在月视图里点某一天，或者点周视图顶上那一行，建的是一件全天的事。到时间时会叫醒它。
- **移动和改时长。** 把你放的事拖到别的时间或别的日子；拖它的下边缘改时长。每次改动都会显示**已保存**和**撤销**。重复的事在表单里改，因为改动对每一次都生效。
- **一件事的卡片。** 点一件事，看是谁放的或谁做的、种类、结果、属于哪个对话；你能改的事带着编辑和删除。做过的事是记录，会一直留着。
- **搜索**在当前这一年的标题和备注里找。
- 左边的**显示**用来隐藏或显示每一类事。**让它自己做事**暂停它自己发起的事，你交代的事照常进行。**今天的预算**显示它主动用了多少、给你留了多少。

## 设置

**设置**（Ctrl+,）盖在窗口上打开。改动随改随存，并显示**已保存**，或者没保存的原因。有两个以上身份时，属于身份自己的那些页面顶上有**作用于**：选这一页是给哪个身份的。属于整台电脑的设置标着**所有身份**。

| 页面 | 里面有什么 |
|---|---|
| 通用 | 语言、主题、是否显示思考过程、通知、是否随电脑启动 |
| 模型 | 默认模型和这个身份自己的模型，点**应用**后先试一次调用再生效；推理强度；保存的模型（启用、停用、移除）；在这台电脑上找到的来源；**添加模型或提供商** |
| 用量 | 花了多少、调用了多少次，按天、按对话、按种类、按模型，范围是今天、7 天或 30 天；今天的额度和**提高今天的额度**（见[限制身份的花费](/docs/zh-cn/use/spending/)） |
| 权限与限额 | 等你决定的事、它做之前先问什么、每天的额度和给你留的那一份、暂停、它主动做多少 |
| 扩展包 | 已安装的包（开关、更新、移除），以及可以搜索和安装的注册表 |
| 学到的东西 | 技能、反射树和记忆：每一项从哪来、用过多少次、和上一个版本的差别、撤销、删除；共享库只读 |
| 连接器 | 渠道、MCP 服务、外部 agent和技能来源，每一类都能添加、测试和移除 |
| 电脑 | 它能在哪些地方工作、在每个地方主动做多少；真实的鼠标和键盘 |
| 个性化 | 它的名字，以及描述它是谁的那些文件 |
| 数据 | 分享、导出角色卡、备份、恢复、从别的产品带过来、停用、删除身份（见[带走身份](/docs/zh-cn/use/take-it-with-you/)） |
| 关于 | 版本、身份的密钥指纹、更新，以及终端里运行的是哪个 `harness` |

### 用量

用你自己的订阅发出的调用（在这台电脑上登录的 agent）按次数计。它们在这里不花钱；旁边显示的标价只供对照，不会算进花费里。

### 连接器

- **渠道**来自渠道包。**添加渠道**先让你从已安装的包里选种类，再按那个包的要求一步步走：它的字段、登录、要进的群，以及用一次性的码把你绑定为主人。没有安装任何渠道包时，页面会说明去哪里装（**设置 › 扩展包**）。
- **MCP 服务**可以按这台电脑上的一条命令添加，也可以按地址添加。添加时会连接一次并列出它的工具；**测试**再连一次。
- **外部 agent**是这台电脑上支持 ACP 的其他 agent。已经登录的可以选作模型。
- **技能来源**是存放技能的文件夹、仓库或地址。**先看看**只读取来源，不安装任何东西。

## 键盘

在 macOS 上，把下面的 Ctrl 换成 Cmd。

| 按键 | 作用 |
|---|---|
| Ctrl+K 或 Ctrl+P | 命令面板：按名字找任何操作、设置页或对话 |
| Ctrl+/ | 快捷键列表 |
| Ctrl+, | 设置 |
| Ctrl+N | 新对话 |
| Ctrl+B | 收起或展开左栏 |
| Ctrl+J | 打开或收起工具面板 |
| Ctrl+F | 在当前对话里查找 |
| Ctrl+Shift+F | 搜索对话 |
| Esc | 关闭或取消打开着的东西；什么都没打开时，停下这一回合 |
| Enter、Shift+Enter | 发送；换行 |
| 上、下 | 在空的输入框里：你发过的消息 |
| 1、2 | 在批准卡片上：选那一项 |
| Shift+F10、F2、Delete | 在列表里的一个对话上：它的菜单、改名、删除 |

在日历里，没有在打字时，单个按键就起作用：

| 按键 | 作用 |
|---|---|
| D、W、M、Y（或 1、2、3） | 日、周、月、年视图 |
| T | 今天 |
| J 或 N，K 或 P | 下一个、上一个日、周、月或年 |
| G | 去某一天 |
| C | 新建一件事 |
| Enter、E | 在一件事上：看它的卡片；编辑它 |
| Delete 或 Backspace | 删除这件事（可以撤销） |
| Z | 撤销刚才的改动 |
| / | 搜索日历 |
| R | 重新读一遍 |

对话框里 Enter 是主按钮，Esc 是取消，Tab 能走到每一个控件。如果不是在桌面应用里、而是在浏览器标签页里打开，浏览器会自己留着其中几个键（Ctrl+N、Ctrl+P）。
